
Bentley InRoads Terrain & Contour Modeling Demo

Project Overview

This project demonstrates the basic concept of Bentley InRoads Terrain and Contour Modeling using a free browser-based contour generation tool.

Tools Used

- Web Browser (Google Chrome / Microsoft Edge)
- Mapscaping Free Online Elevation Contour Generator

Steps Performed

1. Opened the contour generator.
2. Selected the required location.
3. Drew a rectangle to define the project area.
4. Chose the contour interval (meters).
5. Generated contour lines.
6. Reviewed the terrain model.
7. Exported the data (optional).

Output

The generated contour lines represent the terrain elevation and demonstrate the basic workflow used in Bentley InRoads for terrain and contour modeling.
