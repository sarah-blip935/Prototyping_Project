
# IT Company Landing Page - Bricks Builder Demo

A simple landing page designed for a fictional IT company (TechNova), built using **Bricks Builder** — a visual page builder plugin for WordPress.

## About This Project
This demo was created to showcase basic page building and design skills using Bricks Builder's drag-and-drop editor.

## Sections Included
- Header with logo and navigation menu (Home, Services, About, Contact)
- Hero section with heading, tagline, and call-to-action button
- Services section (Web Development, App Development, Cloud Solutions, IT Support)
- About Us section
- Contact/CTA section
- Footer

## Tools Used
- **Bricks Builder** (WordPress page builder plugin)
- **Try Bricks Playground** (free hosted demo environment)
