
# Solana Wallet Balance Checker

A simple demo built using **Solana web3.js**, tested on **Solana Playground** (beta.solpg.io), that connects to the Solana **Devnet** and checks a wallet's SOL balance.

## What this project does

1. Connects to Solana's Devnet using Playground's built-in connection (`pg.connection`)
2. Generates a new wallet (Keypair)
3. Checks and prints that wallet's SOL balance
4. Also checks and prints the balance of Playground's own connected wallet

## Tech Used

- [Solana web3.js](https://solana.com/docs/clients/javascript)
- [Solana Playground](https://beta.solpg.io) (online IDE for writing and running Solana code)

## How it was run

This code was written and executed directly inside **Solana Playground**, using the built-in `client.ts` file under the Client section of a project. No local installation was required.

## Output

A screenshot of the terminal output after running the script is included in this repo (`output-screenshot.png`), showing the connection status, generated wallet address, and balance results.
